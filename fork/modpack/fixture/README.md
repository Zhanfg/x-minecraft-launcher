# P0-04 original Fabric smoke pack

A minimal, fully original (non-Mojang, non-third-party) test pack generated by `scripts/fork/build-smoke-pack.py`. The output is a **Modrinth-format `.mrpack`** compatible with XMCL's existing modpack import path, subject to runtime testing.

- Minecraft 1.21.1, Fabric loader 0.16.14.
- A metadata-only Fabric mod `p0_client_smoke` with `environment = client`. No executable Java entrypoint and no third-party mod binary.
- An empty resource pack with pack format 34.
- A harmless test config file.
- Uses `client-overrides` so the client-specific resources are not placed on a dedicated server by a compliant installer.
- No game assets, user credentials, personal saves, private server files or network hosts are embedded.
- ZIP entry ordering/timestamps fixed for reproducible SHA256.

```sh
python3 scripts/fork/build-smoke-pack.py --check
python3 scripts/fork/build-smoke-pack.py
```

CI validates the archive structure, client-only mod marker, resource pack version and SHA256, then uploads the generated pack. This **does not** prove that XMCL can import it, log in and launch Minecraft; the next acceptance step is a licensed Minecraft runtime smoke test on Windows.

The production modpack will be created after receiving real mod choices and server address; this synthetic fixture is not intended to substitute for a complete gameplay pack.
